Why Network Models?

Imagine you’re studying friendships in a high school. You have data on who nominated whom as a friend, plus information about each student (gender, race, grade). A natural first instinct is to run a logistic regression: does sharing the same gender predict friendship?

The problem is that friendships aren’t independent observations. Some students are more social (they nominate lots of friends), some are more popular (they receive lots of nominations), and friendships tend to be reciprocated: if Alice names Bob, Bob is more likely to name Alice. A standard regression ignores all of this, and your standard errors will be wrong.

The Additive and Multiplicative Effects (AME) model handles these dependencies directly. It gives each actor a sender effect (\(a_i\), how social they are), a receiver effect (\(b_j\), how popular they are), and a position in a latent space (\(u_i\), \(v_j\)) that captures who tends to connect with whom beyond what the covariates explain. The additive effects enter as \(a_i + b_j\); the latent positions enter multiplicatively as the dot product \(u_i'v_j\). Think of it as a regression that takes network structure seriously.

The Data

We’ll analyze a friendship network from the Add Health study, a longitudinal study of adolescents in the United States. The addhealthc3 dataset in lame contains a directed friendship nomination network along with student characteristics.

library(lame)
library(ggplot2)
set.seed(6886)

# load the Add Health friendship network
data(addhealthc3)

# binary friendship: any nomination counts
Y <- (addhealthc3$Y > 0) * 1
X_nodes <- addhealthc3$X

# keep the students whose covariates are all recorded
has_covs <- complete.cases(X_nodes)
Y <- Y[has_covs, has_covs]
X_nodes <- X_nodes[has_covs, ]

n <- nrow(Y)
cat("Students:", n, "\n")
#> Students: 30
cat("Friendships:", sum(Y, na.rm = TRUE), "\n")
#> Friendships: 113
cat("Network density:", round(mean(Y, na.rm = TRUE), 3), "\n")
#> Network density: 0.13

Notice the na.rm = TRUE calls: the diagonal is NA because self-ties are undefined. NAs stay in the matrix and ame() treats those dyads as unobserved, filling them in by data augmentation. A dyad with a missing covariate is treated the same way. Two of the 32 students in the file have no recorded race, so every dyad they belong to would be unobserved; the analysis uses the other 30.

Building Covariates

The classic question in friendship networks is homophily: do birds of a feather flock together? We’ll test whether students are more likely to be friends with others of the same gender, race, and grade.

We include both same_grade (binary) and grade_diff (continuous: grades apart). They measure nearly the same thing, and the results below show how the model divides the grade signal between two overlapping covariates.

# outer() compares every pair of students: 1 if they share the attribute, 0 if not
same_female <- outer(X_nodes[, "female"], X_nodes[, "female"], "==") * 1
same_race <- outer(X_nodes[, "race"], X_nodes[, "race"], "==") * 1
same_grade <- outer(X_nodes[, "grade"], X_nodes[, "grade"], "==") * 1
# absolute grade difference, a continuous covariate
grade_diff <- abs(outer(X_nodes[, "grade"], X_nodes[, "grade"], "-"))

# stack into an n x n x p array
Xdyad <- array(NA, dim = c(n, n, 4))
Xdyad[, , 1] <- same_female
Xdyad[, , 2] <- same_race
Xdyad[, , 3] <- same_grade
Xdyad[, , 4] <- grade_diff
dimnames(Xdyad)[[3]] <- c('same_female', 'same_race', 'same_grade', 'grade_diff')
for (k in 1:4) diag(Xdyad[, , k]) <- NA

# nodal covariates (sender and receiver characteristics)
Xrow <- X_nodes[, c("female", "grade")]
Xcol <- X_nodes[, c("female", "grade")]

Fitting the Model

Now the fun part. We fit a binary probit AME model with:

  • Covariates for homophily effects
  • Sender and receiver random effects (sociality / popularity)
  • Dyadic correlation (reciprocity)
  • 2-dimensional latent space (residual clustering)

A note for ERGM users: what AME assumes

If you’re coming from ergm / statnet, the key difference is the dependence assumption. ERGM uses change statistics (e.g. gwesp, triangle, kstar) to encode unconditional higher-order dependence: changing one tie shifts the probability of other ties directly. AME instead assumes conditional dyadic independence: given the additive effects \((a_i, b_j)\), the latent positions \((u_i, v_j)\), the dyadic correlation \(\rho\), and the covariates, all dyads are independent, and higher-order structure is captured indirectly by integrating over the latent effects.

Three practical consequences:

  • No degeneracy. AME avoids the model-degeneracy failure modes of ERGMs with triangle or unconstrained kstar terms.
  • No change-statistic interpretation of \(\beta\). A coefficient on same_grade is a partial association on the probit-latent scale, not a log-odds change conditional on the rest of the network.
  • Check the dependence summaries you need. Joint posterior predictive checks assess whether the chosen rank and covariates reproduce the observed clustering and other network summaries.
fit <- ame(
    Y,
    Xdyad = Xdyad,
    Xrow = Xrow,
    Xcol = Xcol,
    R = 2, # 2D latent space
    family = "binary", # probit model for 0/1 data
    rvar = TRUE, # sender random effects
    cvar = TRUE, # receiver random effects
    dcor = TRUE, # dyadic correlation (reciprocity)
    verbose = FALSE,
    posterior_opts = posterior_options(
        save_ab = TRUE, save_UV = TRUE,
        thin_ab = 1, thin_UV = 1
    ),
    gof = TRUE
)

Let’s unpack the key results:

Homophily effects. The grade_diff coefficient is strongly negative and its credible interval excludes zero: students further apart in grade are much less likely to be friends. The same_female coefficient is positive (gender homophily) but its 95% credible interval includes zero: the data do not separate the effect from zero. The same_race coefficient captures race homophily after controlling for grade and gender.

Overlapping covariates. same_grade and grade_diff measure nearly the same thing – a grade difference of 0 is the same-grade event. The model puts the grade signal on grade_diff: its posterior mean is -0.73 with a 95% interval of [-1.03, -0.48]. same_grade is left with the residual bump at zero distance on top of that linear trend, 0.2 with an interval of [-0.43, 0.83]. To read the grade effect off a single coefficient, include one of the two.

Variance components. The sender variance (va) and receiver variance (vb) quantify how much students differ in sociality and popularity. The dyadic correlation (rho) captures reciprocity: values near 1 mean that if A nominates B, B almost always nominates A back. Reciprocity is strong here.

For binary networks with a probit link, the coefficients are on the latent scale, and the textbook “\(0.4 \times \beta\)” rule for converting them to probability changes is only sharp when the baseline probability is near 0.5 – which this sparse network is not. Compute the quantity you want directly: predict(fit, type = "response") returns tie probabilities, and contrasting them under counterfactual covariate settings gives the probability change.

Did the Sampler Converge?

The model is estimated via MCMC (Markov chain Monte Carlo), so trace plots are the first check that the sampler explored the posterior thoroughly.

trace_plot(fit, params = "beta", ncol = 3)

ame() also checks convergence itself. It runs two independently seeded chains by default (chains = 2; the seeds are seed and seed + 1000) and, before returning, checks the intercept, va, vb, ve and rho of each chain for drift and compares the two chains on the coefficients, the variance components and summaries of the additive and latent effects. A quantity passes when its split rank-normalised \(\hat R\) is at most its threshold (1.05, or the larger value settled chains reach by chance when many quantities are compared on a short run) and the chains hold enough effective draws on it to have caught a disagreement of one posterior standard deviation. Chains that have not settled are continued together, up to three times, and a fit is returned only when no chain drifts and no \(\hat R\) is above its threshold. fit$rhat lists each \(\hat R\) with its threshold and verdict, and summary(fit) prints them in its Rhat and Threshold columns.

The call above uses the default run length (burn = 500, nscan = 10000, odens = 25). It returned 800 draws from 2 chains, and every \(\hat R\) in the summary is below its threshold. rho has the smallest effective sample size of the stored parameters in this fit, so its trace is the one to look at next:

trace_plot(fit, params = "variance", include = "Dyadic correlation")

What to look for: Traces should fluctuate around a stable mean (long trends mean non-convergence) and densities should be smooth and unimodal.

Read the resulting split-\(\hat R\), bulk ESS, and tail ESS together; the usual targets are \(\hat R\) below 1.01 and an ESS of at least 400. Model comparison: loo() and loo_compare()

PSIS-LOO leaves out one cell at a time, which matches a model with independent residuals, so the two candidates are fitted with dcor = FALSE.:

loo_null <- loo::loo(fit_ll_null)

loo_dyad # elpd_loo and the Pareto k table

loo::loo_compare(list(with_dyad = loo_dyad, no_dyad = loo_null))

The dyadic covariates raise the expected log predictive density by about 65, with a standard error near 12. The Pareto-\(k\) table counts the dyads the leave-one-out approximation handles well: 862 of the 870 for the model with the dyadic covariates and 866 for the one without, and loo() flags the rest. A run four times as long returns the same estimates with one dyad flagged in each model. To choose the latent dimension R on a single network of this size, score dyads the fit never saw, as in Comparing R on held-out ties; there R = 2 is ahead of R = 0 on every fold.

loo() and waic() score normal, binary, Poisson and explicit-cutpoint ordinal (ordinal_cutpoints = "explicit") fits with dcor = FALSE; symmetric fits count each unordered dyad once. See ?loo.ame.

Does the Model Fit the Data?

Goodness-of-fit (GOF) checks whether the model can reproduce structural features of the observed network – degree heterogeneity, reciprocity, clustering – beyond dyad-level prediction.

gof_plot(fit)

In each panel the grey histogram is the posterior-predictive distribution from networks simulated out of the fitted model, and the dashed black vertical line is the observed value. See ?gof_plot for the statistics = ... aliases and the exact column names stored in fit$GOF.

The observed values for sender and receiver degree heterogeneity and for dyadic dependence (essentially empirical reciprocity) fall inside their posterior-predictive histograms: the random effects, the variance components, and \(\rho\) model those three features directly. Triangle closure has no term of its own in an AME model; the latent positions reproduce it through clustering of the \(u_i\) and \(v_j\). Here the share of simulated networks at or above the observed value is 0.12 for triadic dependence and 0.13 for transitivity, so both observed values lie inside the central 95 percent of the simulated ones. Comparing these two panels across values of R shows how much closure each added latent dimension accounts for; when triangle closure is itself the estimand, an ERGM closure term models it directly.

You can also compute GOF after the fact using the gof() function, which accepts custom statistics. The built-in trans.dep panel is a correlation-style clustering measure; ERGM users will typically want the raw clustering coefficient (sna::gtrans, the scalar summary that gwesp(decay = 0, fixed = TRUE) targets), which takes a few lines as a custom stat:

# clustering coefficient: transitive triples over two-paths
trans_ratio <- function(Y) {
    Yb <- Y; Yb[is.na(Yb)] <- 0 # missing ties count as 0
    YY <- Yb %*% Yb
    triangles <- sum(YY * Yb) # transitive triples
    two_path <- sum(YY) - sum(diag(YY)) # two-paths (potential triangles)
    c(trans_ratio = triangles / max(two_path, 1))
}

gof_custom <- gof(fit, custom_gof = trans_ratio, nsim = 50, verbose = FALSE)
obs <- gof_custom[1, "trans_ratio"]
sim <- gof_custom[-1, "trans_ratio"]

# posterior predictive p-value (right tail): near 0 means under-predicted
c(
    observed = round(obs, 3),
    sim_mean = round(mean(sim), 3),
    pp_p_right = round(mean(sim >= obs), 3)
)
#>   observed   sim_mean pp_p_right 
#>      0.485      0.411      0.060

Read this the way you would read ergm::gof(): pp_p_right is the fraction of simulated networks at or above the observed value, so a value near 0 means the model under-predicts the statistic. Here it is 0.06 across 50 joint posterior replicates. These replicates retain uncertainty in the actor effects and latent positions as well as the regression coefficients. See ?gof for adding further custom statistics (raw triangle counts, degree assortativity, and so on).

Visualizing the Latent Space

The multiplicative effects (\(u_i'v_j\)) place each student in a 2D latent space: students near each other in sender space (triangles) nominate similar friends, and students near each other in receiver space (circles) are nominated by similar students. Clusters likely share some unobserved characteristic (same social group, same extracurriculars) that drives friendship choices beyond gender, race, and grade.

uv_plot(fit, layout = "biplot", show.edges = FALSE, label.nodes = FALSE)

Making Predictions

The model gives you predicted probabilities for every possible tie, useful for link prediction and for understanding dyad-level fit. For sparse networks, predicting “no tie” for every dyad already gets most predictions right, so raw accuracy flatters the model – judge it against the modal-class baseline.

pred_resp <- predict(fit, type = "response")

# observed and predicted ties as vectors
Y_vec <- as.vector(Y)
pred_vec <- as.vector(pred_resp)
keep <- !is.na(Y_vec)

# classification at a 0.5 threshold
pred_binary <- (pred_vec[keep] > 0.5) * 1
confusion <- table(Actual = Y_vec[keep], Predicted = pred_binary)
knitr::kable(confusion, caption = "Confusion matrix (threshold = 0.5)")
Confusion matrix (threshold = 0.5)
0 1
0 750 7
1 55 58 

accuracy <- sum(diag(confusion)) / sum(confusion)
baseline <- max(mean(Y_vec[keep]), 1 - mean(Y_vec[keep])) # accuracy of always predicting the modal class
cat(
    "\nAccuracy:",
    round(accuracy, 3),
    " | Baseline (predict modal class):",
    round(baseline, 3),
    " | Lift:",
    round(accuracy - baseline, 3),
    "\n"
)
#> 
#> Accuracy: 0.929  | Baseline (predict modal class): 0.87  | Lift: 0.059

The model classifies 92.9% of dyads correctly, against 87% for always predicting “no tie”.

For link prediction, AUC-style metrics evaluate the model’s ability to rank true ties above non-ties across all thresholds. For sparse networks PR-AUC is the more informative summary: a model that always predicts “no tie” already has AUROC near 0.5 but PR-AUC near the network density, so the gap between PR-AUC and density is the metric of substantive interest.

# AUROC with pROC
roc_obj <- pROC::roc(
    response = Y_vec[keep],
    predictor = pred_vec[keep],
    quiet = TRUE
)
auroc <- as.numeric(pROC::auc(roc_obj))

# ROC and precision-recall AUCs with precrec; PR-AUC suits rare ties
ev <- precrec::evalmod(scores = pred_vec[keep], labels = Y_vec[keep])
precrec::auc(ev) # AUROC and PR-AUC side by side
#>   modnames dsids curvetypes      aucs
#> 1       m1     1        ROC 0.9776949
#> 2       m1     1        PRC 0.8720484

cat(
    "AUROC:",
    round(auroc, 3),
    "\n",
    "Baseline AUROC (random ranker):",
    0.5,
    "\n",
    "Baseline PR-AUC (density of Y):",
    round(mean(Y_vec[keep]), 3),
    "\n"
)
#> AUROC: 0.978 
#>  Baseline AUROC (random ranker): 0.5 
#>  Baseline PR-AUC (density of Y): 0.13

Here PR-AUC is 0.872 against a density baseline of 0.13, and AUROC is 0.978 against 0.5 for a random ranker. These are in-sample ranking summaries; the next section scores dyads the model never saw.

Held-out link prediction

For a held-out evaluation, mask a random subset of dyads to NA before fitting (the sampler excludes them from the likelihood via data augmentation), then score predict(fit, type = "response") on the masked indices. Stratify the split on Y so the test set contains both classes.

# 80/20 stratified mask of off-diagonal dyads
set.seed(6886)
off_diag <- which(row(Y) != col(Y) & !is.na(Y))
pos_idx <- off_diag[Y[off_diag] == 1]
neg_idx <- off_diag[Y[off_diag] == 0]
test_idx <- c(
    sample(pos_idx, round(0.2 * length(pos_idx))),
    sample(neg_idx, round(0.2 * length(neg_idx)))
)

Y_train <- Y
Y_train[test_idx] <- NA # mask test dyads from the likelihood

fit_train <- ame(
    Y_train,
    Xdyad = Xdyad,
    Xrow = Xrow,
    Xcol = Xcol,
    R = 2,
    family = "binary",
    rvar = TRUE,
    cvar = TRUE,
    dcor = TRUE,
    verbose = FALSE,
    gof = FALSE
)

pred_train <- predict(fit_train, type = "response")

# evaluate_heldout() scores the predictions on a logical test mask
test_mask <- matrix(
    FALSE,
    nrow(Y),
    ncol(Y),
    dimnames = dimnames(Y)
)
test_mask[test_idx] <- TRUE
heldout_metrics <- evaluate_heldout(
    y_obs = Y,
    y_pred = pred_train,
    mask = test_mask,
    family = "binary"
)
heldout_metrics
#>   n_eval    auroc     auprc      brier   logloss
#> 1    174 0.923985 0.6889672 0.06946585 0.2215399
cat(
    "Test dyads:",
    length(test_idx),
    " | positives:",
    sum(Y[test_idx] == 1),
    "\n"
)
#> Test dyads: 174  | positives: 23

On the 174 evaluated held-out dyads (23 true friendships), AUROC is 0.924 and PR-AUC is 0.689. The random-ranking references are 0.5 and the test-set density 0.132, and the in-sample values were 0.978 and 0.872: the model ranks friendships it never saw well above chance. Report the evaluated count and positive count alongside the scores; see ?evaluate_heldout for definitions and options.

Do the latent positions help? Comparing R on held-out ties

The same masking answers the question most users bring to an AME model: do the multiplicative effects predict ties that the covariates and the sender and receiver effects do not? Mask each fifth of the dyads in turn, fit the model with and without latent positions, and score the masked dyads:

# five stratified folds over the dyads, the same for both models
set.seed(6886)
scored <- which(row(Y) != col(Y))
fold <- integer(length(Y))
for (v in 0:1) {
    idx <- scored[Y[scored] == v]
    fold[idx] <- sample(rep(1:5, length.out = length(idx)))
}

# fit one model with a fold masked, then score that fold
score_fold <- function(k, R) {
    Y_k <- Y
    Y_k[fold == k] <- NA
    fit_k <- ame(
        Y_k,
        Xdyad = Xdyad,
        Xrow = Xrow,
        Xcol = Xcol,
        R = R,
        family = "binary",
        gof = FALSE,
        verbose = FALSE
    )
    m <- evaluate_heldout(
        y_obs = Y,
        y_pred = predict(fit_k, type = "response"),
        mask = matrix(fold == k, nrow(Y), dimnames = dimnames(Y)),
        family = "binary"
    )
    data.frame(R = R, fold = k, m[c("n_eval", "auroc", "auprc", "logloss")])
}
cv <- do.call(rbind, lapply(c(0, 2), function(R) {
    do.call(rbind, lapply(1:5, score_fold, R = R))
}))

# mean ranking metrics over the folds, and the log score summed over the held-out dyads
cv$log_score <- -cv$logloss * cv$n_eval
aggregate(cbind(auroc, auprc) ~ R, data = cv, FUN = mean)
aggregate(log_score ~ R, data = cv, FUN = sum)

The latent positions are ahead on every one of the five folds. Averaged over the folds, AUROC rises from 0.87 with R = 0 to 0.89 with R = 2 and PR-AUC from 0.55 to 0.60. The log score summed over the 870 held-out dyads rises from -234.2 to -219.0. All ten fits run at the default length.

Simulating from the Model

You can generate new networks from the fitted posterior. A posterior predictive check asks: does a network simulated from posterior draws look like the observed one on a feature you care about (here, overall density)? Observed values inside the simulated distribution mean the model reproduces that feature; values in a tail mean it is missing something.

sims <- simulate(fit, nsim = 100)

# simulated and observed densities
sim_densities <- sapply(sims$Y, function(y) mean(y, na.rm = TRUE))
obs_density <- mean(Y, na.rm = TRUE)

ggplot(data.frame(density = sim_densities), aes(x = density)) +
    geom_histogram(bins = 20) +
    geom_vline(
        xintercept = obs_density,
        linewidth = 1,
        linetype = "dashed"
    ) +
    labs(
        title = "Posterior predictive check: network density",
        subtitle = "Dashed line = observed; histogram = simulated from the model",
        x = "Network density (mean tie probability)", y = "Replicate count"
    ) +
    theme_bw() +
    theme(
        panel.border = element_blank(),
        axis.line = element_blank(),
        axis.ticks = element_blank(),
        legend.position = "top",
        plot.title = element_text(hjust = 0),
        plot.subtitle = element_text(hjust = 0),
        plot.caption = element_text(hjust = 0)
    )

Practical Tips

Choosing R (latent dimensions). Start with R = 0 (no latent space), then try R = 1 and R = 2 and compare GOF and held-out prediction; R = 2 or R = 3 suits most networks. Any rank below the network size is fitted, so choose R by comparing fit.

MCMC settings. The defaults (burn = 500, nscan = 10000, odens = 25) are the length of a final run: 400 stored draws from each of two chains, checked against each other and continued automatically if they have not settled. For exploratory work, burn = 500, nscan = 2000, odens = 25, chains = 1 runs one chain of 80 stored draws with the drift check. Read convergence from fit$rhat and trace_plot().

Variance components. Include rvar = TRUE and cvar = TRUE unless you have a specific reason not to. Include dcor = TRUE for directed networks where reciprocity is plausible.
